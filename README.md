**SUNSET BAY** is an original open-world crime game that runs entirely in the browser from a single HTML file (78.5 KB, zero dependencies, fully offline). Explore a pastel art-deco city with a beach, pier and marina, rendered in a hand-written Canvas 2D software-3D engine.

- **15 missions** — from First Steps and Borrowed Wheels to Heat Check, Valet, Five-Star Tourist and the Sunset Finale, then free roam
- **5-star wanted system** — SBPD interceptors chase, ram and bust you; lose them or reach the safehouse
- **Car jacking & driving** — 8 traffic cars with lane AI, collisions and damage
- **Shops, safehouse & radio** — buy snacks, espresso and style at the Palm Cola Shop, clear your heat at home, unlock two synthesized chiptune radio stations
- **Day–night cycle** — a full 24-hour clock every 2 real minutes: sunset skies, lit windows, headlight cones
- **Save & continue** — press S to save money, mission, position and clock to localStorage
- Full HUD with mission checklist, money, HP, clock, wanted stars and a live minimap

Controls: **WASD** walk / drive · **SHIFT** run · **E** enter / exit car · **F** use zone · **1–3** buy in shop · **R** radio · **M** mute · **S** save

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 — or simply open `game/index.html` in any browser. No build step, no network needed.
